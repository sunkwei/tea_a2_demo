### 0.2 术语

| 术语 | 含义 |
|---|---|
| **锁式线迹**（lockstitch） | 上线与下线在**布层中间**交织打结的线迹，家用平缝机的基本针法 |
| **上线 / 下线** | 穿在机针上、从梭芯引出的两根线 |
| **线环**（loop） | 机针上升时，上线被布料摩擦滞留、在针眼上方鼓出的一个套 |
| **旋梭**（rotary hook） | 连续旋转的钩状零件，转到针位时勾住线环，带着它绕过梭芯 |
| **梭芯 / 梭芯套**（bobbin / bobbin case） | 装下线的线轴与它的壳；线环从壳外侧滑脱 |
| **挑线杆**（take-up lever） | 主轴带动的连杆，负责收线、把线迹拉紧 |
| **送布牙**（feed dog） | 针板下方带齿的板，抬起时把布料向后推一个针距 |
| **针距**（stitch length） | 每针布料移动的距离，送布行程与它对应 |
| **相位 t** | 一个针迹周期归一化到 `[0,1)` 的位置；画面是 t 的纯函数 |
| **相位表** | 把 t 的区间映射到「各零件处于什么状态 / 哪条讲解文案」的**唯一数据源** |

本文其余内容均为本轮推导（标 `【推导】`）；凡是没人拍过板的地方一律进第 10 节，不自行定案。

## 1. 背景与目标

### 1.1 背景

「一根针只是上下动，为什么能缝出扯不开的线迹」这件事，静态图讲不清：

- 线环是**三维**的：上线要绕过藏在梭芯套里的下线；
- 旋梭、梭芯、挑线杆、送布牙四套机构**严格同步**，任意一个时序错了，线迹就不成立；
- 最容易被误解的一点是「针把线钉进布里」——实际是上下两根线在布层中间互相锁住。

仓库里已有同类「可视化讲解」先例（`attention-film` 逐帧由 t 决定的短片、`rubiks-cube` 手写 WebGL 教程），本项目是同一类的小体量动画。

### 1.2 目标（可衡量）

| ID | 目标 |
|---|---|
| G-1 | 一个没接触过缝纫机的人，看完**一个周期**（≤ 40 秒）能说出「上线绕过下线，结扣在布中间」，而不是「针把线钉进布」 |
| G-2 | 能看见**线环 → 被旋梭勾住 → 绕过梭芯 → 脱出 → 被挑线杆收紧**这条完整链路，而不是只画针上下 |
| G-3 | 能看见**送布时序**：针在布内时送布牙在针板下方，针抬起时送布牙才送布 |
| G-4 | 单页、离线、双击可看；1440×900 与 390×844 两种视口下关键标注不被截断 |

### 1.3 成功标准

1. 第 7 节 AC 清单全部通过；
2. 用户本人至少完整看一遍，确认「线环是怎么来的」看得懂（这是主观项，需一次确认）。

## 5. 演示内容（科学内容清单）

### 5.1 一个针迹周期（t ∈ [0,1)）的 8 个相位

> 下表区间是**推导的默认值**，必须以 Q-08 的资料核对后定稿（见 R-01）。动画只要求与最终相位表一致，不要求与下表逐帧相同。

| 相位 | t（默认） | 机针 | 旋梭 | 挑线杆 | 送布牙 | 画面 / 讲解重点 |
|---|---|---|---|---|---|---|
| P1 入布 | 0.00–0.12 | 下行，穿过布料 | 空转 | 下行送线 | 在针板下最低位 | 针带着上线穿过布层 |
| P2 最低点起升 | 0.12–0.25 | 到最低点后开始上升 | 尖端转向针位 | 下行到底，开始回抽 | 仍在针板下 | 上线被布料拖住，针眼上方开始鼓包 |
| P3 成环 | 0.25–0.37 | 继续上升，针眼露出布面 | 尖端接近线环 | 回抽 | 仍在下 | **线环形成**（不是针尖分叉） |
| P4 勾线 | 0.37–0.48 | 升到行程上部 | **尖端勾住线环** | 回抽 | 仍在下 | 旋梭把线环带走 |
| P5 绕梭芯 | 0.48–0.62 | 开始下一循环的下降 | 带着线环绕过梭芯套 | 上行 | 开始抬升 | 线环从梭芯**外侧**绕过去（关键） |
| P6 脱出 | 0.62–0.72 | 下降中，尚未入布 | 线环从梭尖滑脱 | 上行收线 | 抬升中 | 线环脱钩的一瞬间 |
| P7 收紧 | 0.72–0.85 | 下降，接近布面 | 空转 | **上行到底，拉紧线迹** | 抬起并向后送布 | 结扣被拉到**布层中间** |
| P8 送布完成 | 0.85–1.00 | 入布前一瞬 | 空转 | 转为送线 | 落下，回到最低位 | 布料移动 1 个针距，进入下一针 |

### 5.2 「不能画错」的三件事

1. **线环来源**：上线在针眼上方被布料摩擦滞留而成套，不是针尖分叉、不是线自己打卷；
2. **线环必须绕过梭芯**，上下线在**两层布之间**交织；结扣若画在布面上或布面下，即为错误；
3. **送布牙在针穿过布料期间不得接触布料**（否则是明显机械错误，见 AC-08）。

### 5.3 允许的简化（须在页面注明「示意图 · 比例与时序经简化」）

- 旋梭每针转一圈还是两圈、挑线杆的具体曲线、各连杆的偏心量 → 以核对后的相位表为准，动画不对机械细节做工程级还原；
- 布料纤维、线的弹性伸长、夹线器（张力盘）的细牙结构；
- 压脚压力、针板与机针的间隙、油路与噪声。

## 6. 功能需求

### 6.1 FR-A 内容与画面

| ID | 需求 |
|---|---|
| FR-A1 | 单页呈现**「整机剖面」+「针迹特写」两个视图**，二者共用同一个相位 t，必须同步【推导】 |
| FR-A2 | 同一相位下所有零件的位置只由相位表插值得到；不允许「靠 CSS/JS 过渡累积时间」导致暂停后位置漂移 |
| FR-A3 | 上线与下线用**两种明显不同的颜色**，并额外用线宽/虚实做第二编码（色盲可辨）；线迹成型后在布料上留下可见痕迹 |
| FR-A4 | 布料随送布牙逐针步进（每周期 1 个针距），并在画面上累积 N 针；可回卷/重置 |
| FR-A5 | 显示当前相位名（P1…P8）并高亮「此刻在动的零件」 |
| FR-A6 | 特写视图提供局部放大，能看清线环绕过梭芯套的过程【推导】 |
| FR-A7 | 标注引线不遮挡线环路径；图例说明上线/下线/梭芯 |
| FR-A8 | 页面显著位置标注「示意图，非工程图」 |

### 6.2 FR-B 播放控制

| ID | 需求 |
|---|---|
| FR-B1 | 打开即自动循环播放一个周期，默认周期 T = 6s（可调数据表）；播放与帧率无关 |
| FR-B2 | 播放 / 暂停（空格） |
| FR-B3 | 速度 0.25× / 0.5× / 1× / 2× |
| FR-B4 | 「单步」按钮：每次前进 1 个相位，停在相位边界 |
| FR-B5 | 时间轴滑块可拖到任意 t，画面即时跟随（暂停状态也成立） |
| FR-B6 | 重置：回到 t=0、布料针数归零 |
| FR-B7 | 系统设置 `prefers-reduced-motion: reduce` 时**不自动播放**，停在 t=0 并提示「点播放」 |

| R-01 | 机构时序画错（旋梭/挑线杆/送布牙相位） | 教学误导，比不做更糟 | 先定相位表（Q-08 核对）再画；selftest 断言关键时序 |
| R-02 | 线环的三维绕线在 2D 剖面上读不出来 | 核心目标 G-2 落空 | 特写视图 + 放大 + 可切换半透明/线框（取决于 Q-02） |
| R-03 | 画面过密（十几个零件同时动） | 看不清、看不懂 | 整机剖面只画轮廓 + 只高亮当前运动件；细节放特写 |
| R-04 | 拖动时间轴导致布料累积错位 | AC-02/AC-06 不稳定 | 针数 = floor(累计 t/周期)，不累加浮点位移 |
| R-05 | 用户想要的是**老式脚踏机**而非家用电动旋梭机 | 整套机构图作废 | Q-01 必须先答，答完再开工 |
| R-06 | 若选三维（Q-02 C）成本显著上升 | 工期 2–3 倍（粗估，非承诺） | 先确认形式；2D 优先 |
| R-07 | 术语/译名不统一（旋梭 vs 摆梭、梭芯 vs 梭子、挑线杆 vs 夹线器） | 读者混淆 | 统一用 0.2 术语表，页面首次出现给解释 |
| R-08 | 直接手改根 `index.html` 被脚本覆盖 | 白改 | 只改 `tools/gen-project-index.mjs` 后重生成 |

sewing-machine/
├── index.html            入口（零构建可双击）
