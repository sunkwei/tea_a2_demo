# 青岛栈桥 & 回澜阁 — 尺寸考证与建模依据

> 建模单位：**米**；坐标原点：**回澜阁几何中心**（八角亭台基中心，标高 Z=0 = 台基面）。
> 本文记录三类尺寸来源：**① 文献直述**、**② 由图纸/面积反推**、**③ 照片剪影校核**。

**1933 年《前海栈桥南段改筑钢筋混合土设计图》**（Wikimedia Commons，原图 2886×1536）读数：

- 平面图底部总长标注 **1470'-0" ≈ 448 m**，与「栈桥全长 440 m」互相印证；
- 立面图跨径标注：**17'-9"**（≈5.4 m）、**35'-0"**（≈10.7 m）、**117'-3"**（≈35.8 m），说明孔桥由若干组墩柱 + 拱跨组成；
- 平面图：桥身南北向，南端进入「个」字形防波堤，堤心为正八角形台基，亭为八角亭（屋顶平面呈八角放射脊线）；
- 立面图：回澜阁为下檐大、上檐小的双层重檐八角攒尖顶，顶部设宝顶 + 旗杆；台基花岗岩砌筑、四周设栏杆。

## 2. 回澜阁（八角亭）

| 项目 | 数值 | 依据 | 性质 |
|---|---|---|---|
| 平面 | 正八角形 | 青岛晚报 / 市南区政务网 | ① |
| 形制 | 民族风**双层双飞檐八角盔顶**亭阁（重檐攒尖顶），黄琉璃瓦顶、深红圆柱托起仿古窗扇 | 百度百科、青岛晚报 | ① |
| 占地面积 | 约 150～151 m² | 百度百科、《青岛市地名保护名录》 | ① |
| 建筑面积 | 约 340 m²（另说 354.12 m²） | 青岛晚报 / 百度百科 | ① |
| 亭柱 | **24 根圆形亭柱**（红柱） | 百度百科、青岛晚报 | ① |
| 内部 | 2 层圆环形厅堂；中央 34 级螺旋楼梯盘旋上二楼 | 百度百科、青岛晚报 | ① |
| 建成 | 1931—1933 年由青岛市政当局建（1933 年落成） | 青岛晚报、2026 年修缮报道 | ① |

### 2.1 由面积反推八角形尺寸

正八角形面积 A = 2√2·R²：

- A = 151 m² → **R ≈ 7.31 m**（对角宽 14.6 m，边长 5.59 m）→ 建模取台基 R = **7.30 m**（与占地吻合）；
- 亭身柱网取 R = 5.80 m（对角宽 11.6 m），比台基内缩 1.5 m 成回廊；
- 二层柱网取 R = 3.90 m（对角宽 7.8 m），内为 34 级螺旋梯所占的圆厅。

### 2.2 由 1933 年设计图反推竖向比例（像素量取）

对图纸「桥之南首正面图 f-f 断面」做逐像素墨迹分析（脚本见 `.tea_agent_run/scripts/analyze_drawing*.py`）：

| 量取项 | 像素 | 说明 |
|---|---|---|
| 下檐口对角宽（角尖→角尖） | 350 | 亭身宽 228 px，屋面/亭身比 = 1.54 |
| 楼面 → 下檐口 | 55 | 一层柱高 |
| 下檐口 → 上檐口 | 72 | 下层屋面升起高度 |
| 楼面 → 宝顶尖 | 151 | |
| 楼面 → 旗杆顶 | 212 | 地面→旗顶 / 下檐宽 = **0.606** |
| 上层小灯笼宽度 | 81 | 图纸顶层为装饰性小亭，非实物二层 |

标定：下檐对角宽 = 17.81 m（1 px ≈ 0.0509 m）→ 比例换算后
一层柱高 2.80 m、下层屋面升起 3.66 m、宝顶 7.68 m、旗顶 10.79 m。

### 2.3 照片剪影校核（③）

用 Wikimedia Commons「Huilan Pavilion」分类下的现状照片（2016 / 2024 等）逐列提取剪影，
确认：双层八角重檐、下檐角部起翘、顶层宝顶 + 旗杆、一层 16 开间 / 二层 8 开间，
以及「下檐对角宽 ≈ 16.4 m（正南立面方向）、总高 ≈ 13.8 m」的量级关系。

### 2.4 取舍

图纸顶层是装饰性小灯笼，而实物二层是可居人的圆环形厅堂（内有 34 级螺旋梯），
故建模把二层加高到 2.8 m、上层屋面对角宽放大到 11.52 m：

| 参数 | 取值 | 依据 |
|---|---|---|
| 台基（八角）外接圆半径 | 7.30 m | ① 占地 151 m² |
| 一层柱网半径 / 柱高 | 5.80 m / 0.36→3.20 m | ② 柱高 2.80 m，+0.4 便于通行 |
| 二层柱网半径 / 层高 | 3.90 m / 6.10→8.90 m | ③ 实物二层可居人 |
| 下层屋面：檐口半径 / 标高 | 7.42 m / 3.20 m，角部起翘 +1.20 m | ② 比例 |
| 下层屋面：内环（上层楼面） | 3.90 m / 6.10 m | 与二层柱网相接 |
| 上层屋面：檐口半径 / 标高 | 4.80 m / 8.90 m，角部起翘 +0.85 m | ② ② |
| 宝顶 / 旗杆顶 | 12.30 m / 13.80 m | ② 旗杆 2.6 m |
| 总高 ÷ 下檐对角宽 | **0.775** | 图纸实测 0.606（实物二层加高所致） |

## 3. 建模最终取值

**回澜阁**：台基八角 R7.30（对角 14.6 m，占地 151 m²）；下檐对角宽 17.81 m、檐口 3.20 m、角起翘 1.20 m；
上檐对角宽 11.52 m、檐口 8.90 m、角起翘 0.85 m；宝顶尖 11.10 m，旗杆顶 13.80 m；柱 16+8=24 根。

**栈桥**：桥面宽 10.00 m、标高 −0.60 m；桥头 6.00→15.65 m（宽 10→22.5 m）；
孔桥 15.65→165.35 m（6 跨圆券 + 桥墩）；引桥 165.35→401.45 m（实堤）；
铁链护栏高 1.10 m、间距 2.50 m；莲花路灯 12 对，灯柱高 4.9 m；
「个」字形防波堤内坡 17 m / 外坡 29 m，北面留口；海平面 −4.00 m。
