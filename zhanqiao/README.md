# 青岛栈桥 & 回澜阁 — Blender 建模

按**真实物理尺寸**建模的青岛栈桥（含南端回澜阁）。仅建建筑本体，不含相机、灯光、人物、水面。

## 文件

| 文件 | 说明 |
|---|---|
| `build_zhanqiao.py` | 建模主脚本（Blender 5.x 兼容），执行后生成 `zhanqiao.blend` |
| `zhanqiao.blend` | 成果文件（58 个对象，约 2.8 万面，**不含相机与灯光**） |
| `verify.py` | 尺寸核对脚本：量取 .blend 实际尺寸并与设计值比对 |
| `preview.py` | 校验渲染：临时加相机/太阳出图到 `preview/`，**不回写 .blend** |
| `dims.md` | 尺寸考证：数据来源、文献数值、由图纸反推的过程与最终取值 |
| `preview/` | 7 张校验渲染（透视/正南立面/正东立面/平面/全景/总平面/侧立面） |

## 运行

```bat
:: 建模
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup --python zhanqiao\build_zhanqiao.py
:: 尺寸核对
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup --python zhanqiao\verify.py
:: 出图（临时相机/灯光，不改 .blend）
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b zhanqiao\zhanqiao.blend --python zhanqiao\preview.py
```

## 坐标系

- 原点 **(0, 0, 0) = 回澜阁八角亭台基几何中心**，Z=0 = 台基顶面（`.blend` 中有 `ORIGIN_HuilanGe_Center` 空物体标记）
- **+Y = 正北**（指向岸边，栈桥自南向北延伸）；**+X = 正东**；+Z 向上
- 海平面 Z = −4.00 m，栈桥桥面 Z = −0.60 m

## 数据来源

见 `dims.md`。要点：

- 文献直述：栈桥全长 440 m / 宽 10 m；现桥身 401.45 m（引桥 236.1 + 孔桥 149.7 + 桥头 15.65）；
  回澜阁占地 151 m²、建筑面积 340 m²、24 根亭柱、两层圆环形厅堂、34 级螺旋梯、黄色琉璃瓦双层双飞檐。
- 比例依据：1933 年《前海栈桥南段改筑钢筋混合土设计图》（Wikimedia Commons 原图 2886×1536），
  用像素级分析量取回澜阁立面各关键标高与宽度（楼面→下檐 55 px、下檐→上檐 72 px、宝顶 151 px、旗杆顶 212 px、
  下檐对角宽 350 px、亭身宽 228 px），再按「下檐对角宽 17.8 m」标定。
- 照片核对：Wikimedia Commons「Huilan Pavilion」分类下的现状照片（2016/2024 等）用于校核平面、柱数与屋面起翘形态。

## 已知取舍

- 1933 年图纸上的顶层为小型「灯笼」，而实物二层是可居人的圆环形厅堂（内有 34 级螺旋梯），
  故建模时把二层加高到 2.8 m、上层屋面对角宽放大到 11.5 m，总高/下檐宽比 = 0.78（图纸实测 0.61）。
- 公开资料未给出檐口/脊高的精确数值，竖向尺寸为图纸比例 + 面积反推 + 照片剪影三重校核，误差约 ±10%。
