# 《AI 小镇：无限人生》操作指南

> 本文件是**玩家手册的唯一事实来源**：
> 游戏内「帮助 → 操作指南」窗口直接读取本文件渲染成多页手册，
> 改这里就等于改了游戏里的手册，不会出现两份文档各说各话。

你是一个新上任的镇长。镇上的居民、每天发生的事、那条说不清的主线，
全部由 LLM 在你眼前现场生成；数字则由一套确定性的规则系统结算。
**同一颗种子 + 同一串操作 = 同一个世界**；不同存档之间，你几乎不会遇到重复的剧情。

---

## 1. 一分钟上手

```bash
cd ai-town
python main.py                 # 启动图形界面
python main.py --offline       # 不联网的离线版（程序化叙述器照样能玩）
python main.py --sim --days 20 # 无头模拟，打印 20 天流水账
python main.py --selftest      # 跑单元测试
python main.py --doctor        # 检查 LLM 连通性
```

进入游戏后只有三件事要做：

1. **在中间输入框写你想做的事** —— 例如「我想去井台看看那封没有署名的信」。
   LLM 会叙述这件事的结果，并给你 **3 个可选分支**。
2. **点一个分支** —— 系统立刻结算：金币、粮食、民心、居民信任、关系，全都写在面板上。
3. **点「结束这一天」** —— 推进一天：产出、口粮、维护费、税收、行情、商队、随机事件一并结算。

一局大概 30~60 分钟。想快速看结局，直接点菜单「游戏 → 结束本局」。

## 3. 核心操作

### 3.1 自由行动（DM 模式）

输入框接受任何描述，游戏不会把你拦在菜单里：

- 「我想去井台看看那封没有署名的信」
- 「把粮食分给缺粮的人家」
- 「找周青山问问他和旧镇长的事」
- 「召集全镇议事」

模型会叙述**结果**并给三个分支，但**不会替你做下一步决定**。
分支里带着后果倾向（例如善待居民 `kind`、花钱 `costly`、建集市 `build:market`），
由规则系统换算成具体数值。

### 3.2 处理事件

右侧「今日事件」列出当天的事。点其中一条 → 中间展开正文与三个分支 → 选一个。
事件分五类：**天灾 disaster / 人情 social / 商机 opportunity / 悬案 mystery / 日常 routine**，
类型决定它对你的资源与民心的影响方向。

### 3.3 与居民对话

- 直接在输入框里**写居民的名字**（如「找沈禾聊聊」），会自动进入对话模式；
- 或点地图上那个人的圆点 → 右侧「档案」页 → 在输入框继续说话。

对话里模型会按这个人的性格、背景、秘密作答：**信任 ≥ 60 的人才会吐露秘密**。
反复对话能拉高信任，信任高了才会解锁更关键的线索。

### 3.4 结束这一天

点输入行右侧的「结束这一天」，或者菜单「操作 → 结束这一天」。
一天之内依次结算：

```
建筑产出 → 建筑维护费 → 口粮 → 税收 → 民心自然回升 → 建筑损耗
→ 行情波动 → 商队到访 → 随机小事（疾病/流民/失窃/野味/修路）→ 日期推进
```

**30 天一季，四季一轮**；冬季产粮只有 40%，口粮消耗却多 50% —— 秋天不屯粮，冬天很难熬。

### 3.5 市场与商队

- 「买5 / 卖5」按市价成交，**买卖有 18% 差价**（卖价低于市价，买价高于市价），低买高卖才有赚头。
- 商队每隔几天到镇上一次，**求购的货物给 1.25~1.55 倍市价**，是快速积累金币的路子；
  但商队待不了太久，卖晚了就没了。
- 工具、书籍、烈酒属于「库存」，由工坊/学堂/酒馆生产，可在市场里出手。

### 3.6 建造与雇工

「建筑」页列出 9 种建筑，点一下即开建（钱和料够才建得成）。
建好后去「档案」页雇人：**人手越多产出越高**，酒馆、学堂这类建筑还会额外涨民心。
每座建筑都有人手上限（农田/伐木场/采石场/矿井/集市/酒馆 4 人，学堂/医馆/工坊 3 人）。

### 3.7 存档、读档、新局与结局

| 菜单 | 作用 |
|---|---|
| 游戏 → 新游戏… | 重开一局，可指定镇名与种子（种子相同＝世界相同） |
| 游戏 → 保存进度 | 存成 JSON，默认放在 `ai-town/saves/` |
| 游戏 → 读取进度… | 读回任意存档 |
| 游戏 → 结束本局（看结局） | 立刻结算结局 |
| 帮助 → 结局列表 | 看全部 18 种结局的标题（不剧透条件） |

## 4. 数值系统

| 名称 | 怎么来 | 怎么花 |
|---|---|---|
| **金币** | 税收（人口 × 1.6 × 民心系数）、集市与酒馆产出、卖货、商队 | 建造、雇人、买粮、事件里的大部分选项 |
| **粮食** | 农田产出（冬天只有 40%）、猎人野味 | 每天按人口消耗（冬天 ×1.5）；不够会掉民心，甚至有人饿死 |
| **木材** | 伐木场 | 建造、事件里的修缮选项 |
| **石料** | 采石场 | 建造 |
| **矿石** | 矿井（有 10% 概率塌方，产量减半） | 工坊造工具 |
| **声望** | 事件与选择 | 结局判定（部分结局要求高声望） |
| **民心**（0~100） | 粮足则回升、酒馆/学堂/医馆、事件选择 | 民心高 → 税收多；民心低 → 税收少、人会走 |
| **信任**（每个居民 0~100） | 对话、事件里的对待方式 | 信任高才肯说秘密；影响结局 |

另外几个隐性数值：**行为倾向**（仁慈/严苛/贪财/勤勉/好奇/交际…）由你的每个选择累积，
**关系网**（谁和谁亲、谁和谁有仇）由 NPC 生成时确定并随互动演化 —— 结局就是看这些累积出来的形状。

| 建筑 | 造价 | 维护 | 人手上限 | 产出 |
|---|---|---|---|---|
| 农田 | 40 金 + 12 木 | 2 | 4 | 粮食 |
| 伐木场 | 50 金 + 10 木 | 3 | 4 | 木材 |
| 采石场 | 60 金 + 16 木 | 3 | 4 | 石料 |
| 矿井 | 90 金 + 20 木 + 10 石 | 4 | 4 | 矿石（会塌方） |
| 集市 | 80 金 + 20 木 + 12 石 | 3 | 4 | 金币 |
| 酒馆 | 70 金 + 25 木 | 4 | 4 | 金币 + 民心 + 烈酒 |
| 学堂 | 120 金 + 30 木 + 20 石 | 5 | 3 | 声望 + 书籍 + 技能 |
| 医馆 | 100 金 + 20 木 + 20 石 | 4 | 3 | 民心 + 抗病 |

每天的固定开支越大 —— 别一口气把家底砸光。

## 6. 记忆与「翻旧账」

你做过的每一件事都会写进镇子的记忆：选了哪个分支、和谁说了什么、建了什么、卖了什么。
之后某一天，这些旧事会**主动找上门**：

- 当年你施恩的人会提着东西来道谢；
- 当年你刻薄过的事会被贴在祠堂门上；
- 你追查过的线索会有人送回来；
- 你雇的人、你修的房子、你谈的买卖，都可能变成新事件的引子。

触发是**确定性规则**（当前处境 + 行为倾向 + 记忆的新鲜度打分），不额外烧 LLM 额度。
所以「把镇子经营好」和「把自己的过去收拾干净」一样重要。

## 7. 结局

一共 **18 种**（含兜底的「寻常镇生」）。判定顺序即稀有度，越特殊的越先判定：

| 结局 | 大致条件倾向 |
|---|---|
| 传奇镇长 | 民心/声望/财富/人口/信任全面拉满 |
| 黄金时代 | 钱多、民心高、人口多 |
| 学院之城 | 学堂升到 2 级且攒够书籍 |
| 商路繁荣 | 交易倾向高 + 财富可观 |
| 巨贾之镇 | 钱极多，但民心/声望跟不上 |
| 群贤毕至 | 每个人都见过、都信你 |
| 仁爱之镇 | 仁慈行为多 + 民心高 |
| 悬案终章 / 悬案未解 | 主线推到头 / 主线断掉 |
| 铁腕镇长 | 严苛行为多 |
| 贪墨者 | 贪财行为多 + 声望低 |
| 流言蜚语 | 人际关系恶劣 |
| 人心离散 | 人口稀少 + 民心低 |
| 粮仓见底 | 断粮 |
| 断壁残垣 | 几乎什么都没剩 |
| 苦冬 | 冬天遇上缺粮 |
| 隐世之镇 | 长期什么都不做 |
| 寻常镇生 | 兜底：不好不坏 |

菜单「帮助 → 结局列表」随时能看标题；具体条件不剧透，但上面的表可以自己当攻略用。

## 8. LLM 与离线模式

- **默认走在线 MiniMax**（`https://api.minimax.cn/v1`，`MiniMax-M3.1-Flash`），
  密钥按顺序自动找：环境变量 `MINIMAX_API_KEY` → 项目 `config.json` → `~/.tea_agent/provider.yaml`。
- **完全离线也能玩**：`python main.py --offline`。此时由程序化叙述器接管，
  事件模板会读当前状态来挑（缺粮就不会给你丰收），玩法一样，只是没那么惊艳。
- **模型偶尔输出坏 JSON**：解析器有三层兜底（修复 → 容错解析 → 取最长配平片段），
  仍失败就自动回退离线叙述器，游戏不会卡死。
- **单次调用 6~10 秒**：这是思考型模型的固有成本，界面在后台线程里调，不会冻住窗口。
- 想换后端：`AITOWN_BACKEND=ollama|openai|offline`，或直接改 `config.json`。

## 9. 常见问题

**Q：点了「行动」没反应？**
A：右下角状态栏会显示「世界正在回应…」。MiniMax 单次调用要 6~10 秒，第一次开局的居民/主线/事件生成要 30 秒左右。

**Q：今天没有事件？**
A：每天固定 3~5 件。如果「今日事件」页签是空的，点一下「结束这一天」再回来看看。

**Q：怎么重来一局？**
A：菜单「游戏 → 新游戏…」，可以指定镇名和种子。

**Q：存档在哪？**
A：`ai-town/saves/` 下的 JSON 文件，菜单「游戏 → 读取进度…」可以直接选。

**Q：能故意玩坏吗？**
A：能，而且这正是重点。民心崩到 20 以下会有人离开，粮吃光会死人，走极端路线会进「铁腕镇长」「贪墨者」这类结局。

**Q：为什么我输入的事模型没照做？**
A：模型只负责叙述，数值与规则由系统说了算。输入越具体（地点、人物、动机），
  它的叙述越贴题；实在不听话时，直接选分支也能推进。

**Q：想让世界更好看/更乱？**
A：种子决定世界底色，`config.json` 里的 `temperature` 决定发散程度，
  `max_tokens` 与提示词长度决定模型想多久。
