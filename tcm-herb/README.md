# 🌿 中药大全 · TCM Herb Atlas

一个**纯前端、离线优先**的中医药科普应用：双击 `index.html` 就能用，不联网也能查 86 味药材、39 个病症、22 首经典方剂。
需要补充资料时，可以接本机 [tea_a2](http://localhost:8383) 联网检索并由模型整理。

> ⚠️ **仅供中医科普学习参考，不构成诊疗建议**，不能替代医师面诊与处方。用药请遵医嘱或咨询执业药师。
> 方剂只列组成与主治，**不提供剂量与煎服法**；含毒药材、老年慢病与严重疾病页面均带就医提示。

## 快速开始

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| **直接双击** | 打开 `tcm-herb/index.html` | `file://` 协议，零依赖零配置，**推荐** |
| **单文件版** | `npm run tcm:build` 后打开 `tcm-herb/tcm-herb.html` | 图片一起内联（约 26 MB），拷到哪都能用 |
| **本地 HTTP（可选）** | `npx serve tcm-herb` 或任意静态服务器 | 与 `file://` 行为一致，便于调试 |

> `file://` 下用**经典 `<script>`** 加载（不用 ES module、不 fetch 本地 JSON），所以双击就能跑。
> 查询历史存在本机 `localStorage`（键名 `tcm-herb/history/v1`），换浏览器/清缓存会丢。

## 五个需求怎么落地的

### 1️⃣ 全 H5，`index.html` 即入口

- 原生 HTML + CSS + JS，无框架、无构建依赖；移动端优先（360–430px 单栏，≥900px 四列）。
- 宣纸底 + 墨绿主色 + 朱砂点缀，跟随系统深浅色，右上角可手动切换。
- Hash 路由：`#/herb/gan-cao`、`#/symptom/pa-jin-sen-bing`、`#/formula/gui-zhi-tang`、`#/search/咳嗽`，浏览器返回键可用。

### 2️⃣ 药材图鉴：图片 + 简介 + 功效 + 属性

86 味常用中药材，每味都有：

| 内容 | 字段 |
| --- | --- |
| 图片 | Wikimedia Commons 实物图（84/86），逐张标注作者与许可；2 味用程序化 SVG 示意图 |
| 简介 | 主治与症见（现代语言） |
| 功效 | 功效标签（如「补脾益气 · 清热解毒 · 祛痰止咳」） |
| 属性 | 性味、归经、升降浮沉、功效分类、用法用量（药典口径，附「遵医嘱」）、炮制、毒性、禁忌、产地、来源 |

- 按 18 个功效分类筛选；毒性非「无毒」的药材在详情页顶部显著警示。
- 详情页可跳转「相关病症」「相关验方」，方剂里的药名也能点回药材（`炙甘草 → 甘草` 这类炮制前后缀会自动回退）。

### 3️⃣ 按病症查药：药材 + 搭配 + 历史验方

39 个病症，**按现代症状/疾病描述**（不用「风寒/肝郁」等证型名），其中：

- 30 个常见病症（感冒、咳嗽、失眠、便秘、高血压、糖尿病……）
- 9 个**老年病种**：帕金森病、胃酸过多、骨质疏松、前列腺增生、老年性皮肤瘙痒、耳鸣听力下降、视物模糊、夜尿频多、阿尔茨海默病
- 原有便秘、失眠、健忘、乏力气短、食欲不振、高血压、糖尿病、风湿关节痛等同时打上「老年常见」标签，不重复建条目

每个病症页给出：

1. **候选药材**，分「主 / 辅」并给一句话依据（如「天麻：平肝息风止颤」）；
2. **常用搭配**（如「黄连 + 吴茱萸：左金丸，肝火犯胃之吞酸」），不提供剂量；
3. **历史验方**：方名、出处（《伤寒论》· 汉）、功效、主治、组成药名与君臣佐使；
4. **就医提示**（严重疾病与老年病种必填），写明「中药仅辅助，不能替代处方药」。

### 4️⃣ 按药材名查询

统一搜索框一次召回三类结果（药材 / 病症 / 方剂），支持：

- 中文正名、别名（国老 → 甘草）、拼音全拼（`gancao`）、**拼音首字母**（`gc` → 甘草）
- 功效关键词（`补气` → 黄芪）、分类名（`清热药` → 该类全部）、主治文本
- 命中高亮 + 「命中：别名 / 功效 / 拼音首字母」标注

### 5️⃣ 历史查询 + 模糊查询 + 联网查询

**历史**：每次搜索与每次打开详情都会记录；同词合并计次并置顶；上限 50 条；点历史直接回到详情或重跑搜索；单条可删、可一键清空（二次确认）。

**模糊**：

| 能力 | 说明 |
| --- | --- |
| 输入归一化 | 去空格/标点、全角→半角、英文小写 |
| 繁简互转 | 内置 198 组繁简对照，「當歸」「金銀花」都能命中 |
| 拼音 / 首字母 | `gancao`、`gc` 均可 |
| 错别字容错 | 编辑距离 1–2，**只作用于正名**（2 字词还要求首字相同），命中标「疑似：可能是错别字」 |
| 多词 AND | 「咳嗽 痰」要求两个词都命中 |
| 不做 | 同音字扩展、语义/向量检索（避免引入大词库与误召回） |

**联网**（自动探测，不设开关）：

- 应用启动静默探测 `GET http://localhost:8383/api/health`；能用就直接用，**不弹任何确认框**。
- 点「联网查」→ `POST /api/llm/chat`，`web_tools: true`（服务端代模型调搜索端点），结果分「AI 整理」+「来源列表」两块展示，每个来源带 URL、相关度、权威度，可点开原链。
- 连不上 → 就地给出可复制的启动指引（`tea_agent --port 8383 --workspace .`）+「重试」，**本地功能完全不受影响**。
- 联网结果标注「未经审核」；默认不写入本地库，需点「记入历史」才留痕。

> 实测契约（tea_agent 1.7.0）：必须显式 `provider: "deepseek"` + `model: "deepseek-flash"` + `reasoning_effort: "none"`。
> 默认 provider 若是 minimax，配 `none` 会 502（上游拒绝）；CC 域名 CORS 为 `*`，`file://` 可直接 fetch。

## 数据与来源

| 类别 | 数量 | 说明 |
| --- | --- | --- |
| 药材 | 86 味 | 18 个功效分类；含甘草、白芍、生姜等方剂基础药与淫羊藿、续断、远志、菊花、海螵蛸、车前子等老年常用药 |
| 病症 | 39 个 | 30 常见 + 9 老年病种（19 个病种同时属于两类） |
| 方剂 | 22 首 | 桂枝汤、麻黄汤、银翘散……左金丸、天麻钩藤饮；**无剂量、无煎服法** |

- 文字：以《中国药典》2020 年版公开条目与公有领域古籍为主要依据，逐条在详情页标注来源；简介为现代语言整理。
- 图片：Wikimedia Commons，只取 **CC0 / Public domain / CC BY / CC BY-SA**；作者、许可、原链写进 `assets/herbs/sources.js` 并显示在药材页底部。
- 图片由 `tools/fetch-images.mjs` 抓取（串行 + 429 退避，遵守 Wikimedia 的抓取约定），可重复运行增量更新。

## 目录结构

```
tcm-herb/
├─ index.html                 # 入口（双击即用）
├─ tcm-herb.html              # 单文件版（npm run tcm:build 生成，已 gitignore）
├─ src/
│  ├─ data-herbs.js           # 86 味药材
│  ├─ data-symptoms.js        # 39 个病症（含主/辅药材、搭配、验方、就医提示）
│  ├─ data-formulas.js        # 22 首方剂（组成 + 君臣佐使，无剂量）
│  ├─ core.js                 # 归一化/繁简/索引/模糊匹配/排序/高亮（纯函数）
│  ├─ storage.js              # 历史查询（含 refId，可回详情）
│  ├─ online.js               # a2 探测 + web_tools 查询 + 来源解析 + 降级文案
│  ├─ app.js                  # 路由与渲染
│  └─ styles.css              # 宣纸墨绿主题 + 深浅色
├─ assets/herbs/              # 图片（84 jpg + 2 svg）与 sources.js（署名）
└─ tools/
   ├─ selftest.mjs            # 57 项离线断言（数据/检索/历史/联网解析）
   ├─ verify.mjs              # 24 项无头 Edge 端到端（file:// 真实交互 + 截图）
   ├─ fetch-images.mjs        # 从 Commons 抓图并生成署名
   └─ build-single.mjs        # 打包单文件版
```

## 命令

```bash
npm run test:tcm        # 57 项离线断言（Node 直跑，无需浏览器/接口）
npm run tcm:verify      # 24 项无头 Edge 端到端（截图在 tcm-herb/tools/shots/）
npm run tcm:verify:online  # 追加一次真实联网（需要本机 a2 在 8383）
npm run tcm:build       # 生成单文件版 tcm-herb.html
npm run tcm:images      # 重新抓取缺失的药材图片并更新署名
```

无头验证依赖本机 Edge，默认路径 `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`，可用 `EDGE_PATH` 覆盖。

## 已知限制

- 图片总量约 20 MB（`loading="lazy"`，首屏只加载可见卡片）；单文件版约 26 MB。
- `localStorage` 在浏览器隐私模式或部分 `file://` 场景下可能不持久，重要查询可以自己记一下。
- 联网结果来自模型与搜索端点，**未经医学审核**，只作资料线索，不作为用药依据。
- 老年病种与慢病页面的定位是「科普 + 就医提示」，不做辨证、不给剂量、不替代专科治疗。
